# otlp-c v0.5.0

Released 2026-08-07.

## Highlights

The "actually complete the TODOs" release. Closes TODOs 20, 21, 22,
23, 24, 27, and 42 with full implementations (prior "Complete"
markers were based on stubs).

## New signals

- Metrics (include/otlp-c/metric.h): counter / gauge / histogram.
- Logs (include/otlp-c/log.h): severity + body + trace correlation.
- Span events + links + trace_state on the traces signal.

## New APIs

- otlp_context_t + otlp_context_inject / _extract via callback carrier
  (include/otlp-c/context.h).
- otlp_sampler_t vtable with always_on / always_off /
  trace_id_ratio_based built-ins (include/otlp-c/sampler.h).
- otlp_slab_t fixed-slot memory pool with malloc fallback
  (include/otlp-c/slab.h).

## Performance

- HTTP keep-alive + connection reuse in the exporter.

## Architectural

- Schema-driven metrics/logs encoders (DRY/OCP).
- Table-driven metric-kind dispatch.
- Shared encoder helpers: otlp_encode_any_value, otlp_emit_resource,
  otlp_emit_instrumentation_scope, otlp_emit_attributes.

## Tests

16 property tests; all passing.

## Compatibility

Linux x86_64, macOS arm64 / x86_64, FreeBSD 14.2. Windows x64 / ARM64
builds with MSVC atomics workaround.
