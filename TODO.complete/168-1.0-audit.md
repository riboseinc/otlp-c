# TODO 168 — The 1.0.0 audit and API freeze

**Status:** Complete (v1.0.0)
**Priority:** the milestone

## The audit (criteria → evidence, at v0.8.0)

1. **Public surface audited** — 133 exported symbols across 10
   headers. The v0.5.104 audit covered 124; the 9 added since
   (otlp_exporter_opts_apply_env + otlp_env_storage_t, the
   otlp_http_header_t opts pair, metrics/logs_endpoint,
   schema_url, and the 7-function exemplar API) were re-reviewed
   for docstrings, return codes, ownership, thread-safety. Two
   gaps found and fixed in this release:
   - otlp_env_storage_t is ~26 KiB — stack placement cost now
     documented (prefer static/heap on constrained stacks).
   - apply_env reads getenv — thread-safety contract now
     documented (call during single-threaded init).
2. **Wire conformance proven** — 32 schema tables pinned against
   upstream literals (31 + the new Exemplar table); whole
   payloads reference-validated by the golden vectors; the
   Jaeger integration job exercises a real otelcol on every PR.
3. **Boundary validation complete** — CWE-93 (user_agent AND the
   v0.7.2 extra headers, both mutation-tested), CWE-190 (every
   allocation site), UTF-8 at every wire-string setter, the
   hardened response parser with a portable byte-fixture suite.
4. **No open P1/P2 items** — TODO.complete complete through 167.
5. **Additive-only held across the whole window** — 0.6.0 through
   0.8.0: every change internal, additive, or docs/tests
   (the one model change, per-signal endpoints, was explicitly
   user-approved and additive at the public surface).

Plus: no stubs (the sole OTLP_ERR_NOT_IMPLEMENTED hit is
strerror's own string mapping); strerror completeness pinned;
CodeQL clean; all five build configurations green at 52/52.

## The freeze

- version.h: "since 1.0.0 the SOURCE API is frozen for 1.x —
  additions only; the C ABI is NOT guaranteed across builds."
- CLAUDE.md versioning section updated to the same language;
  the stale "(v0.5.97)" preamble corrected.
- README/quickstart FetchContent tags → v1.0.0.

## Known, documented non-goals for 1.x

TLS (sidecar — ADR-0004), gRPC, payload compression
(zero-non-libc-deps invariant); exemplar filtered_attributes;
per-signal TIMEOUT env vars. The path to the first three is a
2.x optional-deps model.
