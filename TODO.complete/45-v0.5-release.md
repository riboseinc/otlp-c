### Tag push (user action)

After PR #26 merges, the user creates and pushes the tag:

```sh
git checkout main && git pull
git tag -a v0.5.0 -m "otlp-c 0.5.0"
git push origin v0.5.0
```

The release workflow (`.github/workflows/release.yml`) triggers on
tag push and builds/publishes artifacts.

Per global rule, the agent never pushes tags.
